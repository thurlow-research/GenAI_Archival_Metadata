# Movie Review Prototype

Pilot: extract structured metadata (schema.org `Review` / `Movie`) from free-flow film review prose.

- **Corpus:** ~2,000 Nitrate Online reviews ([`ScottThurlow/nitrateonline`](https://github.com/ScottThurlow/nitrateonline))
- **Ground truth:** schema.org JSON-LD embedded in a number of the review files
- **Status:** prototype; schema, extractor, and evaluation to be added here
